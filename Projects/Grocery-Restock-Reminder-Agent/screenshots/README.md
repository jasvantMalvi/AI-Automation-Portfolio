# Screenshots

This folder contains visual documentation for the Grocery Restock Reminder Agent.

## Screenshot Files

1. `workflow-overview.png` — n8n flow showing the daily schedule, Google Sheets read, restock eligibility Code node, OpenAI-powered reminder generation, and Telegram send node.
2. `customer-restock-sheet.png` — Example customer restock table with name, Telegram chat ID, last purchased items, last purchase date, and restock interval.
3. `telegram-reminder-messages.png` — Example personalized grocery restock reminders sent through Telegram.

The Google Sheets screenshot uses sample customer data and repeats the same ChatId across rows. It should not be interpreted as evidence of correct per-customer routing.

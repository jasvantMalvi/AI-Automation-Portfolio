2. `google-sheets-feedback-records.jpg` — Example feedback rows with ratings, sentiment, topics, suggestions, priority, input type, timestamps, and duplicate status. Student names, IDs, feedback text, and Telegram identifiers are blurred.

These are example execution screenshots, not a guarantee that the sanitized JSON is ready for production without reconnecting credentials and repairing the documented configuration issues.

# Screenshots

This folder contains visual documentation for the Office Holiday Notifier.

## Screenshot Files

1. `workflow-overview.jpeg` — n8n workflow showing the daily schedule, holiday retrieval, upcoming-holiday filtering, IF check, and Gmail send node.
2. `holiday-calendar.jpeg` — Google Sheets `Holidays` worksheet showing holiday name, date, type, and notification lead time.
3. `holiday-email-example.jpeg` — Gmail example of the generated Office Holiday Announcement HTML email.

The Gmail example currently has an empty holiday table. The exported workflow's IF condition is inverted, so this screenshot illustrates the current defect rather than a successful upcoming-holiday alert. Sender details are redacted in the public copy.

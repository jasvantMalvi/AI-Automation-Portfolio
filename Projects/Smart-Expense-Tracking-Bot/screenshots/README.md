# Screenshots

This folder contains visual documentation for the Smart Expense Tracking Bot.

## Screenshot Files

1. `workflow-overview.png` — n8n workflow showing WhatsApp input, JavaScript expense parsing, Google Sheets append/read operations, summary generation, and WhatsApp response.
2. `expense-google-sheet.png` — Example Google Sheets expense ledger with date, time, original message, amount, currency, category, merchant, payment method, and status columns.
3. `whatsapp-expense-summary.png` — Example WhatsApp interaction showing recorded expense entries and a generated expense summary.

The public WhatsApp screenshot copy has the displayed phone number blurred. The spreadsheet screenshot contains example transaction data.

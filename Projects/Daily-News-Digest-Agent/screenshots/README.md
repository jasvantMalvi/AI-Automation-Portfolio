# Screenshots

This folder contains visual documentation for the Daily News Digest Agent.

## Screenshot Files

1. `workflow-overview.png` — Full n8n architecture with the daily trigger, five Google News RSS feeds, merge, deduplication/ranking, AI article analysis, Google Sheets, digest generation, and Google Docs output.
2. `google-sheets-news-tracker.png` — Article-level Google Sheets records with headline, summary, category, sentiment, trend, importance score, source, publish date, and URL.
3. `digest-document-top-stories.png` — Example generated Google Doc showing the top-stories section.
4. `digest-document-category-section.png` — Example digest continuation showing the category-organized news section.
5. `google-drive-digest-files.png` — Google Drive folder view containing generated digest documents. Multiple documents for the same report date are visible; the README flags this as a likely multiple-item document-creation issue to verify.

The screenshots show sample output dated 28 August 2026. They are not live news.

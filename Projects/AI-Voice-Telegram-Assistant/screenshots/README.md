# Screenshots

This folder contains visual documentation for the AI Voice Telegram Assistant.

1. `workflow-overview.png` — n8n workflow architecture showing the Telegram voice trigger, file download, ElevenLabs transcription, GPT-5 Mini AI Agent, Conversation Memory connection, ElevenLabs speech generation, and Telegram audio reply.

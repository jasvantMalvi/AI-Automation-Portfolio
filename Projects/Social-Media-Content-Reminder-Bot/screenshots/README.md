# Screenshots

This folder contains visual documentation for the Social Media Content Reminder Bot.

## Screenshot Files

1. `google-sheets-content-tracker.png` — Example content records, platforms, scheduled times, statuses, and tracking columns.
2. `telegram-reminder-interaction.png` — Telegram reminder message with the inline **Completed** action and completion acknowledgement.

These screenshots illustrate the tracker structure, reminder experience, and the two n8n workflow paths.

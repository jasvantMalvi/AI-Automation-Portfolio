# Screenshots

This folder contains visual documentation for the AI Powered Tasks Generator Bot.

## Screenshot Files

1. `workflow-overview.png` — n8n workflow showing Telegram input, AI Agent, OpenAI Chat Model, JavaScript task parsing, Google Sheets append, and Telegram confirmation.
2. `google-sheets-task-records.png` — Example task rows stored in Google Sheets, including ID, task title, description, priority, and estimated time.
3. `telegram-plan-generation.png` — Telegram conversation with sample planning requests and success messages showing the number of tasks generated.

The screenshots are examples of workflow outputs. The visible Sheets columns also show that deadline and category are not currently mapped into the task log.

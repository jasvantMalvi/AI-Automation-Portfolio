# Screenshots

This folder contains visual documentation for Meeting Scheduler Automation.

## Screenshot Files

1. `workflow-overview.png` — Annotated n8n workflow showing Google Sheets intake, date/time processing, Calendar availability check, conditional routing, event creation, sheet updates, and Gmail responses.
2. `successful-scheduling-execution.png` — Execution view showing the available-slot branch through event creation, status update, and confirmation email.
3. `unavailable-slot-execution.png` — Execution view showing the unavailable-slot branch through rejection status update and requester email.
4. `form-responses-sheet.png` — Google Forms response sheet with requester, meeting, date/time, duration, and status columns.
5. `meeting-confirmation-email.png` — Example confirmation email containing the scheduled meeting details.
6. `meeting-unavailable-email.png` — Example rejection email explaining that the requested time slot is unavailable.

The public screenshot copies have been blurred to hide requester names, email addresses, and personal contact details.

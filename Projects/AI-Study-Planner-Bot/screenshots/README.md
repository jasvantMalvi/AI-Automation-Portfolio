# Screenshots

This folder contains visual documentation for the AI Study Planner Bot.

## Screenshot Files

1. `workflow-overview.png` — n8n architecture showing Telegram input, JavaScript student-detail extraction, Claude study-plan generation, HTML construction, file conversion, and Telegram document delivery.
2. `telegram-study-plan-delivery.png` — Telegram examples showing structured study requests and generated HTML study-plan document attachments.
3. `html-study-plan-overview.png` — Example generated HTML plan showing the student overview, exam date, goal, subjects, weak subjects, study days, and preferred study time.
4. `html-study-plan-weekly-plan.png` — Example generated HTML plan showing weekly schedule, subject priorities, revision and practice, and final-days plan.

The HTML plan screenshots are historical examples dated 23 September 2026. Names in the example images are obscured for public documentation.

# Screenshots

This folder contains public-safe visual documentation for the Automated Certificate Delivery Agent.

## Screenshot Files

1. `workflow-overview.png` — Full n8n workflow showing manual start, Google Sheets pending-row lookup, recipient field mapping, looping, template copy, placeholder replacement, document sharing, sheet update, and Gmail delivery.
2. `google-sheets-recipient-tracker.png` — Recipient table with certificate status, certificate link, error field, and sent timestamp. Personal names, email addresses, phone numbers, and document links are blurred.
3. `certificate-template.png` — Google Docs template showing the four dynamic placeholders: full name, course name, completion date, and recipient ID.
4. `generated-certificates-folder.png` — Google Drive output folder containing generated certificate files. Recipient names in file names are obscured.
5. `generated-certificate-example.png` — Example personalized certificate document. Recipient name is obscured; template structure and certificate fields remain visible.
6. `certificate-delivery-email.png` — Example personalized Gmail delivery email. Sender identity, account email, recipient name, and certificate ID are obscured.

The screenshots demonstrate a sample run dated 23 October 2026. They are sample execution evidence, not proof of delivery for every future run.

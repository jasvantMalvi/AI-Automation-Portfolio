# Screenshots

This folder documents the AI Image Generator Bot and distinguishes between the included workflow export and an alternate Telegram-delivery version.

## Screenshot Files

1. `workflow-drive-upload.png` — Matches the supplied `workflow.json`: Telegram Trigger → Message a model → Generate an image → Upload file to Google Drive.
2. `alternate-telegram-photo-delivery.png` — An alternate n8n version ending with a Telegram `Send a photo message` node. This node is not present in the included JSON.
3. `telegram-generated-image-example.png` — Example Telegram conversation showing generated social-media images delivered in chat. It illustrates the alternate delivery behavior, not the included Drive-upload export.

The uploaded Google Drive screenshot is intentionally omitted because it shows a general Drive home view rather than a generated file or output folder.

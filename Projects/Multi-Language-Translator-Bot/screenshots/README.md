# Screenshots

This folder contains visual documentation for the Multi Language Translator Bot.

## Screenshot Files

1. `workflow-overview.png` — n8n workflow showing manual execution, editable input text, AI translation, Anthropic Chat Model, Structured Output Parser, report formatting, file conversion, and Google Drive upload.
2. `google-drive-output-files.png` — Cropped view of generated translation report files in the Google Drive file list. Unrelated personal Drive files have been excluded from this public copy.
3. `translation-report-preview.png` — Preview of a generated translation report showing detected source language, language count, original text, language index, and translation sections.

The report preview represents one demonstration run and does not independently verify the accuracy of every generated translation.

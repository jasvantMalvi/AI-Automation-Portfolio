# Screenshots

This folder contains visual documentation for the Skill Gap Analyzer Bot.

## Screenshot Files

1. `workflow-overview.png` — n8n workflow showing form submission, PDF text extraction, AI Agent, OpenAI Chat Model, Structured Output Parser, Google Sheets append, and Gmail delivery.
2. `report-overview.png` — Top section of the generated email report, showing candidate overview, target role, experience level, readiness score, and skills.
3. `report-roadmap.png` — Lower section of the report showing recommended next steps and the short-/medium-term learning roadmap.
4. `google-sheets-record.png` — Google Sheets analysis record with candidate details, skills, recommendations, roadmap, and readiness score.

Candidate names and email addresses are blurred in public screenshot copies. Sample report values are examples only and do not establish an objectively validated readiness score.

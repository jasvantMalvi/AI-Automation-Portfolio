# Project Screenshots

This folder contains visual documentation of the Monthly Client Work & Billing Automation System built using n8n, Google Sheets, PDF generation, and Telegram.

## Workflow Overview

**File:** `workflow-overview.png`

The screenshot demonstrates the complete automation workflow, including:

- Telegram command handling
- Client details retrieval from Google Sheets
- Monthly work-record retrieval
- Client-wise billing calculations
- Invoice data preparation
- PDF invoice generation
- Invoice delivery through Telegram
- Monthly report history storage
- Automated monthly billing summary

## Notes

- The workflow uses Google Sheets as its client and work-log data source.
- PDF invoices are generated for individual clients.
- Telegram is used for invoice delivery and monthly summaries.
- Configure your own credentials and spreadsheet references before execution.
- Sensitive client information and credentials must not appear in public screenshots.

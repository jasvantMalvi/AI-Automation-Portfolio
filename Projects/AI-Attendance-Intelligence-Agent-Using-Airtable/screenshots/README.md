# Project Screenshots

This folder contains visual documentation of the **AI Attendance Intelligence Agent Using Airtable**, built using n8n, Airtable, and an AI model.

## Workflow Overview

**File:** `workflow-overview.png`

The screenshot displays the complete automation workflow, including:

- Weekly attendance schedule trigger
- Fetching student records from Airtable
- Processing attendance statistics
- AI-powered attendance analysis
- HTML attendance report generation
- Saving reports to Airtable
- Sending reports through Gmail
- Updating email delivery status in Airtable

## Notes

- The screenshot shows the workflow structure and node execution indicators.
- The demonstration uses sample student attendance data.
- Student information and private credentials should not be exposed in public screenshots.
- This screenshot documents the workflow design; it does not independently prove every scheduled execution will succeed.

## About

This portfolio showcases practical projects that combine **AI agents, automation workflows, APIs, and business tools**. The focus is on reducing repetitive work, connecting applications, and building useful automated systems.

## Project Areas

- **Business & Operations** — billing, invoices, registrations, and reporting
- **Customer Communication** — WhatsApp, Telegram, and email assistants
- **Education & Career** — attendance, study planning, and job alerts
- **Data & Documents** — document processing, analysis, and presentations
- **Productivity & Lifestyle** — reminders, scheduling, and personal assistants
- **Specialized Prototypes** — grocery planning, healthcare concepts, and maintenance workflows

## Tools & Technologies

**n8n · OpenAI · Google Gemini · JavaScript · REST APIs · Webhooks · Google Sheets · Google Drive · WhatsApp · Telegram · Airtable**

## Explore the Repository

Start with the **[Project Index](./Projects/README.md)** to browse all 52 projects by category. Individual project folders contain documentation and, where available, workflow exports, screenshots, and setup notes.

## Important Notes

- Workflows may need your own credentials, IDs, and configuration before use.
- Test each workflow with sample data before using it in a real process.
- Projects have different levels of completeness; check each README for scope and known limitations.
- Never add API keys, passwords, tokens, or private customer information to public files.

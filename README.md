## 👋 About this portfolio

This repository documents practical automation projects designed to connect AI capabilities with real workflows. The projects cover business operations, customer communication, productivity, education, document processing, research, and more.

Most workflows are built in **n8n**, combining triggers, data processing, conditional logic, AI models, integrations, and automated outputs. The goal is to demonstrate how repetitive tasks and multi-step processes can be made more structured and efficient.

This is a growing portfolio of hands-on builds and prototypes—not a claim that every workflow is production-ready.

## 🧩 Common automation patterns

Across the projects, you’ll find examples of:

- Trigger-based workflows using forms, schedules, email, and messaging platforms.
- Input validation, data cleanup, normalization, and duplicate checks.
- AI-powered classification, summarization, content generation, and recommendations.
- Structured JSON outputs and JavaScript-based data transformation.
- Conditional routing, loops, status updates, and multi-step workflow orchestration.
- Integrations with spreadsheets, databases, documents, and communication tools.

## 🔍 How to explore

1. Open the **[complete project index](./Projects/README.md)**.
2. Choose a project and open its folder.
3. Read its project documentation and review the included workflow or supporting files.
4. Before importing a workflow, configure your own credentials, IDs, environment values, and service permissions.

## ⚠️ Notes before reusing workflows

- Workflow exports may require configuration changes before they run in your n8n instance.
- Connect your own accounts and credentials. Never publish API keys, access tokens, passwords, or private customer data.
- Sample records and screenshots are for demonstration; verify mappings and test with safe data before using a workflow in a real process.
- Some projects are prototypes and may have known limitations documented in their individual folders.
- The medical-assistance project is a technical prototype only. It is **not clinically validated** and must not be used for diagnosis, emergency triage, or treatment decisions.
